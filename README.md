# Amenity Maps Site

This folder is a GitHub Pages-ready static site for public amenity maps.

## Publish workflow

1. Create a GitHub repo (recommended: `amenity-maps`)
2. Push this folder's contents to that repo root
3. Enable GitHub Pages from the `main` branch `/ (root)`
4. Public URL will be:
   - `https://<github-username>.github.io/amenity-maps/`

## Add a new map

1. Save the new HTML map into `maps/`
2. Update `index.html` to include the new link
3. Commit + push
